
#  Password Checker

Password Checker
A simple HTML-based web tool that validates password strength and generates secure passwords using user-provided information. Built as a beginner-friendly mini project to demonstrate front-end form validation, basic logic, and deployment using GitHub and Vercel.
 Live Demo
Explore the live app here: mini-project-file-upload.vercel.app
Project Structure
password-checker/
├── index.html       # Main interface and navigation
├── password.html    # Password validation and generation logic


 Features
-  Password Strength Checker
Validates password length, character types, and overall strength.
-  Random Password Generator
Creates secure passwords using user inputs like name, birthdate, or keywords.
-  Responsive Design
Works across desktop and mobile browsers.
-  Live Deployment
Hosted on Vercel for fast and free access.


##  Technologies Used

- HTML5
- GitHub for version control
- Vercel for deployment

##  How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/om25x/password-checker.git
   ```
2. Open `index.html` or `password.html` in your browser.
3. Enter a password to test its strength.

##  Deployment

This project is deployed using [Vercel](https://vercel.com), enabling fast and free hosting for static sites.
